# 📰 App de Notícias

Aplicativo mobile desenvolvido em **React Native**, com sistema de autenticação e exibição de notícias de forma organizada e responsiva.

O projeto simula uma plataforma de notícias, com notícia principal, cabeçario, rodapé e outras notícias.

---

## 📱 Funcionalidades

- 🏠 Tela inicial com listagem de notícias
- 📰 Visualização de conteúdo
- 🎨 Componentes reutilizáveis (Header e Footer)

---

## 🛠 Tecnologias Utilizadas

- React Native
- JavaScript
- Node.js

---

## Organização do Código

O projeto está dividido em:

- **Componentes** → Header e Footer
- **Modelos** → Usuário e outros modelos  

---

## Objetivo Acadêmico

Aplicar conhecimentos de desenvolvimento mobile utilizando React Native, reforçando organização estrutural, reutilização de componentes e integração com backend.
